Title: React Casino Site

The casino site was rebuilt on React, with content and translations moved out of the code and into a headless CMS so the editorial team could work without a release.

I built UI features in the React/Redux frontend and implemented the automated end-to-end tests with Webdriver.io, while holding the Team Lead role. The system is unit tested with Jest and Enzyme throughout.

The frontend is deployed to a CDN and backed by a DDD-layered Express caching and proxy service running in Docker. Content and translations live in Contentful, and the codebase is structured as small npm packages.
