Title: HTML5 Poker Client

The second generation moved the rendering into the browser: instead of streaming pixels from the server, the client draws the table itself, which cuts bandwidth and keeps the client responsive on a weak connection.

I designed and implemented it. The table is rendered on canvas with KineticJS from cached, prescaled vector graphics, text and images, and the same models and controllers drive several different user interfaces.

Built on Backbone, RequireJS and a custom MVC framework, with views in both HTML/CSS and jQuery Mobile, audio through the Web Audio API with a Soundmanager2 fallback, translations with Jed, and duplex server communication over two XMLHttpRequest channels using long polling for server-to-client events. Source in SVN.
