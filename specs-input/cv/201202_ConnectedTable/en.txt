Title: Server-Rendered HTML5 Poker Client

The first web poker client worked much like remote desktop: everything except the buttons was rendered on the server and streamed to the browser as draw commands, so the client stayed thin and the table looked identical everywhere.

I developed and maintained it — the Qt/C++ rendering server and the browser client that draws the incoming commands on an HTML5 canvas and plays sound from audio sprites.

Implemented in C++/Qt on Linux and in HTML, CSS and JavaScript in the browser, with game traffic over XMLHttpRequest and source in SVN.
