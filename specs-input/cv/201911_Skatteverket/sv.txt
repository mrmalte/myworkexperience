Title: React-prototyp

Den andra prototypen av samma filuppladdningstjänst, den här gången för att utvärdera React i sig: hur affärslogik hålls skild från gränssnittet, och hur tillstånd hanteras utan bibliotek för tillståndshantering.

Jag byggde den med React hooks och Context API för tillstånd, och affärslogiken i ett eget lager.

Enhetstestad med Jest och Enzyme, källkod i GitHub Enterprise, driftsatt på OpenShift via Jenkins CI/CD-pipelines.
